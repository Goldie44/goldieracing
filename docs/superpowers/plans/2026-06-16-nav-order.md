# Réordonnancement des pages du menu — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permettre à l'utilisateur de réordonner par glisser-déposer les pages du menu de navigation (sidebar desktop + drawer mobile), avec persistance locale qui survit aux redémarrages de l'app.

**Architecture:** Un contexte React (`NavOrderContext`) détient la liste ordonnée des pages et la persiste dans `localStorage`. Un composant partagé `NavList` rend soit des liens cliquables normaux, soit une liste glissable (`@hello-pangea/dnd`), selon un état local `isEditMode` géré par `Layout`. `Layout` utilise `NavList` deux fois : sidebar desktop et drawer mobile, partageant le même ordre via le contexte.

**Tech Stack:** React 18, react-router-dom, `@hello-pangea/dnd` (déjà une dépendance), `@heroicons/react`, `localStorage`. Pas de framework de tests dans `apps/web` (aucun `*.test.*` existant) — la vérification se fait manuellement via `pnpm dev`, comme pour les fonctionnalités précédentes du projet.

### Task 1: Créer le contexte `NavOrderContext`

**Files:**
- Create: `apps/web/src/lib/NavOrderContext.tsx`

- [ ] **Step 1: Écrire le fichier du contexte**

```tsx
import { createContext, useContext, useEffect, useState } from "react";
import {
  BeakerIcon,
  CalendarDaysIcon,
  ChartBarIcon,
  CubeIcon,
  Squares2X2Icon,
  WalletIcon,
} from "@heroicons/react/24/outline";

const NAV_ORDER_STORAGE_KEY = "goldie-racing:nav-order";

const navItemsSource = [
  { path: "/", icon: Squares2X2Icon, label: "Dashboard" },
  { path: "/calendar", icon: CalendarDaysIcon, label: "Calendrier" },
  { path: "/stock", icon: CubeIcon, label: "Stock Pièces" },
  { path: "/performance", icon: ChartBarIcon, label: "Performance" },
  { path: "/budget", icon: WalletIcon, label: "Budget" },
  { path: "/rd", icon: BeakerIcon, label: "R&D" },
];

const mergeOrder = savedPaths => {
  const remaining = new Map(navItemsSource.map(item => [item.path, item]));
  const ordered = [];

  for (const path of savedPaths) {
    const item = remaining.get(path);
    if (item) {
      ordered.push(item);
      remaining.delete(path);
    }
  }

  // Pages absentes de l'ordre sauvegardé (ajoutées par une mise à jour de
  // l'app depuis la dernière sauvegarde) sont ajoutées à la fin, dans leur
  // ordre source.
  for (const item of navItemsSource) {
    if (remaining.has(item.path)) ordered.push(item);
  }

  return ordered;
};

const loadStoredOrder = () => {
  if (typeof window === "undefined") return navItemsSource;

  try {
    const stored = window.localStorage.getItem(NAV_ORDER_STORAGE_KEY);
    if (!stored) return navItemsSource;

    const parsed = JSON.parse(stored);
    if (!Array.isArray(parsed)) return navItemsSource;

    return mergeOrder(parsed);
  } catch (error) {
    console.error("Unable to load nav order", error);
    return navItemsSource;
  }
};

const NavOrderContext = createContext(null);

export function NavOrderProvider({ children }) {
  const [orderedItems, setOrderedItems] = useState(loadStoredOrder);

  useEffect(() => {
    try {
      window.localStorage.setItem(
        NAV_ORDER_STORAGE_KEY,
        JSON.stringify(orderedItems.map(item => item.path))
      );
    } catch (error) {
      console.error("Unable to save nav order", error);
    }
  }, [orderedItems]);

  const reorder = (fromIndex, toIndex) => {
    setOrderedItems(prev => {
      const next = [...prev];
      const [moved] = next.splice(fromIndex, 1);
      next.splice(toIndex, 0, moved);
      return next;
    });
  };

  return (
    <NavOrderContext.Provider value={{ orderedItems, reorder }}>
      {children}
    </NavOrderContext.Provider>
  );
}

export function useNavOrder() {
  return useContext(NavOrderContext);
}
```

This follows the same load/merge/persist pattern as `apps/web/src/lib/AtrContext.tsx` (storage key prefix `goldie-racing:`, `useEffect` persistence, try/catch around `localStorage`).

### Task 3: Créer le composant partagé `NavList`

**Files:**
- Create: `apps/web/src/components/NavList.tsx`

This component renders the list of nav items either as plain clickable links
(normal mode) or as a drag-and-droppable list (edit mode). It is shared by
the desktop sidebar and the mobile drawer so the rendering logic isn't
duplicated.

- [ ] **Step 1: Écrire le composant**

```tsx
import { Link } from "react-router-dom";
import { Bars2Icon } from "@heroicons/react/24/outline";
import { DragDropContext, Droppable, Draggable } from "@hello-pangea/dnd";

export default function NavList({
  items,
  activePath,
  isEditMode,
  droppableId,
  onReorder,
  onItemClick,
}) {
  const handleDragEnd = result => {
    if (!result.destination) return;
    onReorder(result.source.index, result.destination.index);
  };

  if (isEditMode) {
    return (
      <DragDropContext onDragEnd={handleDragEnd}>
        <Droppable droppableId={droppableId}>
          {provided => (
            <div ref={provided.innerRef} {...provided.droppableProps}>
              {items.map((item, index) => (
                <Draggable key={item.path} draggableId={item.path} index={index}>
                  {dragProvided => (
                    <div
                      ref={dragProvided.innerRef}
                      {...dragProvided.draggableProps}
                      {...dragProvided.dragHandleProps}
                      className="flex items-center gap-3 px-3 py-2.5 rounded-lg text-sm font-medium text-muted-foreground bg-secondary/50 mb-1"
                    >
                      <Bars2Icon className="w-4 h-4 text-muted-foreground/60" />
                      <item.icon className="w-4 h-4" />
                      {item.label}
                    </div>
                  )}
                </Draggable>
              ))}
              {provided.placeholder}
            </div>
          )}
        </Droppable>
      </DragDropContext>
    );
  }

  return (
    <>
      {items.map(item => {
        const isActive = activePath === item.path;
        return (
          <Link
            key={item.path}
            to={item.path}
            onClick={onItemClick}
            className={`flex items-center gap-3 px-3 py-2.5 rounded-lg text-sm font-medium transition-all duration-200 ${
              isActive
                ? "bg-primary/10 text-primary"
                : "text-muted-foreground hover:text-foreground hover:bg-secondary"
            }`}
          >
            <item.icon className="w-4 h-4" />
            {item.label}
            {isActive && (
              <div className="ml-auto w-1.5 h-1.5 rounded-full bg-primary" />
            )}
          </Link>
        );
      })}
    </>
  );
}
```

Notes on the props contract (so later tasks call it correctly):
- `items`: array of `{ path, icon, label }` from `useNavOrder().orderedItems`.
- `activePath`: `location.pathname`, used to highlight the active link in
  normal mode (ignored in edit mode).
- `isEditMode`: boolean, switches between the two render branches.
- `droppableId`: string, must be unique per `NavList` instance on the page
  (desktop sidebar and mobile drawer render at the same time when the drawer
  is open, so they need distinct ids).
- `onReorder(fromIndex, toIndex)`: called on drop, maps directly to
  `useNavOrder().reorder`.
- `onItemClick`: optional click handler on each `Link` in normal mode (used
  by the mobile drawer to close itself on navigation; omitted on desktop).
